# LegalVault AI — API Contract (v1 skeleton)

**Version:** 0.1 (skeleton — no implementations yet) · **Base URL:** `http://localhost:8000` · **All paths prefixed with `/v1/`**

Auth: `Authorization: Bearer <jwt>` header on every non-auth endpoint. Errors follow:

```json
{ "error": "InvalidCase", "code": "CASE_404", "detail": "case_id not found" }
```

The live spec will be auto-generated by FastAPI at `/docs` (Swagger UI). This markdown is the design contract we agree on *before* writing code.

---

## OpenAPI 3.1 skeleton

```yaml
openapi: 3.1.0
info:
  title: LegalVault AI API
  version: 0.1.0
  description: |
    Locally-deployed retrieval and verification system for legal documents.
    See ../TRD.md §5 for the design rationale.
servers:
  - url: http://localhost:8000/v1
    description: Local dev

security:
  - bearerAuth: []

paths:
  # ─────────── Auth ───────────
  /auth/login:
    post:
      summary: Password login
      security: []
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [email, password]
              properties:
                email: { type: string, format: email }
                password: { type: string, minLength: 12 }
      responses:
        '200':
          description: JWT issued
          content:
            application/json:
              schema:
                type: object
                properties:
                  jwt: { type: string }
                  user: { $ref: '#/components/schemas/User' }
        '401': { $ref: '#/components/responses/Unauthorized' }

  # ─────────── Cases ───────────
  /cases:
    post:
      summary: Create a new case
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [name, doc_type]
              properties:
                name: { type: string, maxLength: 200 }
                client_name: { type: string, nullable: true }
                doc_type:
                  type: string
                  enum: [contract, audit_report, agreement, other]
      responses:
        '201':
          description: Case created
          content:
            application/json:
              schema:
                type: object
                properties:
                  case_id: { type: string, format: uuid }
    get:
      summary: List user's cases
      responses:
        '200':
          description: OK
          content:
            application/json:
              schema:
                type: array
                items: { $ref: '#/components/schemas/Case' }

  /cases/{id}:
    get:
      summary: Case detail with documents
      parameters:
        - { name: id, in: path, required: true, schema: { type: string, format: uuid } }
      responses:
        '200':
          description: OK
          content:
            application/json:
              schema:
                type: object
                properties:
                  case: { $ref: '#/components/schemas/Case' }
                  docs:
                    type: array
                    items: { $ref: '#/components/schemas/Document' }
        '403': { $ref: '#/components/responses/Forbidden' }
        '404': { $ref: '#/components/responses/NotFound' }

  # ─────────── Documents ───────────
  /cases/{id}/documents:
    post:
      summary: Upload PDF or audio
      description: |
        Non-blocking. Returns immediately with a task_id. Poll /status
        endpoint to check ingestion progress. Max 50MB per document.
      parameters:
        - { name: id, in: path, required: true, schema: { type: string, format: uuid } }
      requestBody:
        required: true
        content:
          multipart/form-data:
            schema:
              type: object
              properties:
                file: { type: string, format: binary }
      responses:
        '202':
          description: Accepted, ingestion enqueued
          content:
            application/json:
              schema:
                type: object
                properties:
                  document_id: { type: string, format: uuid }
                  task_id: { type: string }
        '413': { description: File too large }
        '415': { description: Unsupported file type }

  /cases/{id}/documents/{doc_id}/status:
    get:
      summary: Poll ingestion status
      parameters:
        - { name: id, in: path, required: true, schema: { type: string, format: uuid } }
        - { name: doc_id, in: path, required: true, schema: { type: string, format: uuid } }
      responses:
        '200':
          description: OK
          content:
            application/json:
              schema:
                type: object
                properties:
                  status: { type: string, enum: [pending, indexing, done, error] }
                  chunk_count: { type: integer }
                  error_message: { type: string, nullable: true }

  /cases/{id}/documents/{doc_id}:
    delete:
      summary: Remove document and purge its vectors
      parameters:
        - { name: id, in: path, required: true, schema: { type: string, format: uuid } }
        - { name: doc_id, in: path, required: true, schema: { type: string, format: uuid } }
      responses:
        '200':
          description: Deleted
          content:
            application/json:
              schema:
                type: object
                properties:
                  deleted: { type: boolean }
                  chunks_removed: { type: integer }

  # ─────────── Query (the main endpoint) ───────────
  /cases/{id}/query:
    post:
      summary: Ask a question about the case
      parameters:
        - { name: id, in: path, required: true, schema: { type: string, format: uuid } }
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [question]
              properties:
                question: { type: string, maxLength: 2000 }
      responses:
        '200':
          description: Answer with cited evidence
          content:
            application/json:
              schema:
                type: object
                properties:
                  answer: { type: string }
                  evidence:
                    type: array
                    items:
                      type: object
                      properties:
                        filename: { type: string }
                        page: { type: integer, nullable: true }
                        ts_start: { type: number, nullable: true }
                        ts_end: { type: number, nullable: true }
                        snippet: { type: string }
                        score: { type: number }
                  confidence: { type: number, minimum: 0, maximum: 1 }
                  latency_ms: { type: integer }
        '429':
          description: Rate limit exceeded
          headers:
            Retry-After: { schema: { type: integer } }

  # ─────────── Report Shield ───────────
  /cases/{id}/shield:
    post:
      summary: Reverse-RAG audit of a report against the case corpus
      parameters:
        - { name: id, in: path, required: true, schema: { type: string, format: uuid } }
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [source_doc_id]
              properties:
                source_doc_id: { type: string, format: uuid }
      responses:
        '200':
          description: Shield report
          content:
            application/json:
              schema:
                type: object
                properties:
                  trust_score: { type: number, minimum: 0, maximum: 1 }
                  verified_count: { type: integer }
                  unverified_count: { type: integer }
                  contradiction_count: { type: integer }
                  missing_sections:
                    type: array
                    items: { type: string }
                  flags:
                    type: array
                    items:
                      type: object
                      properties:
                        claim: { type: string }
                        verdict: { type: string, enum: [Verified, Unverified, Contradicted] }
                        evidence_chunk_id: { type: string, format: uuid, nullable: true }
                        confidence: { type: number }

  # ─────────── Export ───────────
  /cases/{id}/export:
    post:
      summary: Build an evidence ZIP for a query or shield run
      parameters:
        - { name: id, in: path, required: true, schema: { type: string, format: uuid } }
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              properties:
                query_id: { type: string, format: uuid, nullable: true }
                shield_report_id: { type: string, format: uuid, nullable: true }
      responses:
        '200':
          description: Download URL (short-lived signed link)
          content:
            application/json:
              schema:
                type: object
                properties:
                  download_url: { type: string, format: uri }
                  expires_at: { type: string, format: date-time }

  # ─────────── Audit log ───────────
  /audit-log:
    get:
      summary: Immutable audit log (admin only)
      responses:
        '200':
          description: OK
          content:
            application/json:
              schema:
                type: array
                items:
                  type: object
                  properties:
                    id: { type: string, format: uuid }
                    user_id: { type: string, format: uuid, nullable: true }
                    action: { type: string, enum: [login, upload, query, shield_run, export, delete] }
                    resource_id: { type: string, format: uuid, nullable: true }
                    created_at: { type: string, format: date-time }
        '403': { $ref: '#/components/responses/Forbidden' }

components:
  securitySchemes:
    bearerAuth:
      type: http
      scheme: bearer
      bearerFormat: JWT

  responses:
    Unauthorized:
      description: Missing or invalid JWT
    Forbidden:
      description: Cross-org access denied
    NotFound:
      description: Resource does not exist

  schemas:
    User:
      type: object
      properties:
        id: { type: string, format: uuid }
        email: { type: string, format: email }
        role: { type: string, enum: [admin, analyst, viewer] }
        org_id: { type: string, format: uuid }

    Case:
      type: object
      properties:
        id: { type: string, format: uuid }
        name: { type: string }
        client_name: { type: string, nullable: true }
        doc_type: { type: string, enum: [contract, audit_report, agreement, other] }
        created_at: { type: string, format: date-time }

    Document:
      type: object
      properties:
        id: { type: string, format: uuid }
        filename: { type: string }
        doc_type: { type: string, enum: [pdf, audio] }
        page_count: { type: integer, nullable: true }
        duration_sec: { type: number, nullable: true }
        status: { type: string, enum: [pending, indexing, done, error] }
        created_at: { type: string, format: date-time }
```

## Notes for implementers

- **Bearer JWT** is required on every path *except* `/auth/login`.
- **UUIDs everywhere** — no auto-increment INTs (see TRD §4).
- **Case isolation is server-side**: every `/cases/{id}/*` route MUST check `case.org_id == user.org_id` before doing anything.
- **413 vs 415**: file too big vs wrong MIME. Both must return before touching disk.
- **202 for uploads**: ingestion is async. Never block the request thread on parsing.
- **Rate limit**: 30 queries/user/minute, 500/org/hour. Enforced by `slowapi` on Redis.
